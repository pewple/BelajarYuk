# Belajar Yuk! — peta jalan

Rujukan: kerangka "empat pilar" pembelajaran (Hirsh-Pasek, Zosh, Golinkoff dkk., 2015,
*Psychological Science in the Public Interest*): aktif (berpikir, bukan sekadar
menekan), terlibat (tanpa pengalih perhatian), bermakna, dan interaksi sosial.
Panduan layar: AAP dan WHO sama-sama menyarankan ≤ 1 jam/hari untuk usia 2–5 tahun
dan didampingi orang dewasa; di bawah 2 tahun sebaiknya tanpa layar.

## Sudah dikerjakan

- [x] Huruf dan angka Arab (hijaiyah, ١ ٢ ٣) di Mengenal Huruf, Belajar Bicara, Berhitung, Labirin
- [x] Dek kata Arab di Belajar Bicara (28 kartu)
- [x] Suara Arab asli bila perangkat punya; ejaan Indonesia sebagai cadangan
- [x] Gerbang soal penjumlahan pada tombol rumah; abu-abu sampai 5 permainan selesai
- [x] Istirahat lembut setelah 15 menit (menunggu jeda alami, maksimal 45 detik)
- [x] Petunjuk yang memudar di Labirin, Kasir, dan Pola (3 benar → lepas, 2 salah → kembali)
- [x] Kunci ketukan ganda (0,35 detik, per kontrol)
- [x] Perintah lisan di setiap modul + tombol ulang + pengingat satu kali saat diam
- [x] Ulangan berjarak (tangga Leitner, hanya di perangkat)
- [x] Aksesibilitas: target ≥ 64 px, kontras diperiksa, gerak dikurangi, dialog modal
- [x] Modul Pola (AB, AAB, ABB, ABC)
- [x] Dapat dipasang sebagai aplikasi dan jalan tanpa internet (PWA)

## Belum / sengaja ditunda

- [ ] Ringkasan untuk orang tua (huruf/angka mana yang sudah mantap, menit hari ini)
- [ ] Mode satu tombol (pindai) untuk anak dengan kendala motorik
- [ ] Dorongan keluar layar di akhir sesi ("cari huruf A di kemasan")
- [ ] Gambar asli (bukan ikon) untuk dek Arab — empat kata memakai gambar buatan sendiri
      (keju, roti, beruang, emas) dan beberapa ikon hanya pendekatan (raʾs = ikon orang)
- [ ] Kata kedua tiap huruf Arab dari daftar awal (أَسَد, بَيْت, تَاج …) sebagai kartu cadangan

## Modul berikutnya

| Modul | Isi | Catatan |
| --- | --- | --- |
| Harakat (Iqra 1) | Fathah, kasrah, dhammah di atas ba, ta, tsa… | Lanjutan alami dari hijaiyah |
| Bentuk & warna | Mencocokkan, menyortir | Bentuk dan warna sudah ada di Pola |
| Mencocokkan / memori | Pasangan gambar–huruf, 4 kartu dulu | Melatih ingatan kerja |
| Tambah sederhana | 1 + 2 dengan benda yang bisa dihitung | Setelah Berhitung dikuasai |
| Menelusuri huruf | Jari mengikuti garis huruf | Kontrol motorik halus; tolerir garis yang meleset |
| Lagu & doa pendek | Lagu anak Indonesia, doa harian dengan teks | Rekam sendiri (hak cipta) |
| Perasaan | Wajah senang/sedih/marah | Kosakata emosi, bagus untuk didampingi |
| Rutinitas harian | Urutkan pagi–malam | Konsep waktu & urutan |

Saran urutan: Harakat → Mencocokkan → Tambah sederhana.
